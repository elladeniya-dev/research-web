# OutfitIQ — R26-IT-052

Project website for **OutfitIQ: A Multi-Engine Intelligent Fashion Recommendation System with Dynamic Preference Learning and Trend Awareness**, an IT4010 research project at the Sri Lanka Institute of Information Technology (SLIIT).

Static HTML/CSS/JS, no build step. Open `index.html` or serve the folder with any static host (e.g. GitHub Pages).

## Pages

- `index.html` — project overview and the four engines
- `domain.html` — research context, gap and objectives
- `milestones.html` — assessments with dates, marks and deliverables
- `documents.html` — proposals, reports and other submissions
- `presentations.html` — presentation slides
- `about.html` — team and supervisors
- `contact.html` — contact details and enquiry form
